# Project Stages

## Prototype 1
Pi Zero 2 W, GPS, MPU6050, optional SSD1306 OLED, USB/Bluetooth ELM327, power bank, local LAN web app and MQTT.

## Vehicle prototype
Use the same software with a real USB or Bluetooth ELM327 in a vehicle, validate real PIDs/DTCs/VIN, power behaviour and driver-event thresholds.

## Final direction
Compact custom hardware/PCB with automotive power protection, GNSS, IMU, CAN/OBD, local storage and cellular/network connectivity.
