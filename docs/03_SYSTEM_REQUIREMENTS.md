# System Requirements

The system shall support dual USB/Bluetooth ELM327 transport, python-OBD capability discovery, core and selectable live signals, VIN when available, automatic DTC collection, protected DTC clearing, GPS, IMU, optional OLED, MQTT, local logging, a LAN web app, Bluetooth setup from that web app, automatic boot and reconnect behaviour.

The web UI must not be required for telemetry collection to continue.
