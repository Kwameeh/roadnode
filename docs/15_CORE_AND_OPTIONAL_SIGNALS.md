# Core and Optional Signals

Default desired core signals:

`RPM,SPEED,COOLANT_TEMP,ENGINE_LOAD,THROTTLE_POS,CONTROL_MODULE_VOLTAGE,FUEL_LEVEL,INTAKE_TEMP,MAF`

Only supported core commands are watched. Other supported live Mode 01 signals appear in the web Signals page and can be selected. Choices persist per vehicle profile, preferably keyed by VIN.
